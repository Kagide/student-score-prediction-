# Student Score Prediction - Elevvo ML Internship Project

## Overview
This project aims to predict student exam scores based on factors such as study hours, attendance, and sleep habits using machine learning regression techniques. It was completed as part of the Elevvo Pathways Internship Program.

## Dataset
- Source:https://www.kaggle.com/code/ahmedezzatibrahem/student-performance-factors
- Features include: study time, attendance rate, sleep hours, and others.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook / VS Code

## Project Workflow
1. Data exploration and cleaning
2. Feature engineering based on attendance, study hours, and sleep
3. Model building using linear regression
4. Model evaluation with metrics such as R², MAE, and MSE
5. Visualization of model predictions vs actual scores

## Results
The model confirmed that study hours, attendance, and sleep are influential factors in predicting exam performance. Students optimizing these habits tend to score higher consistently.
